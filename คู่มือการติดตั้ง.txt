========================================================================
   คู่มือการติดตั้งและใช้งานระบบขายหน้าร้าน PJ Copy Shop (POS System)
========================================================================

📌 ข้อกำหนดเบื้องต้นของเครื่องคอมพิวเตอร์:
- ระบบปฏิบัติการ Windows 10 หรือ Windows 11 (64-bit)
- มีการเชื่อมต่ออินเทอร์เน็ตสำหรับการติดตั้งครั้งแรก (เพื่อดาวน์โหลดและอัปเดตระบบ)

------------------------------------------------------------------------
🛠️ ขั้นตอนที่ 1: ติดตั้งระบบ (ดับเบิลคลิกเพียง 1 ครั้ง ระบบทำให้หมด)
------------------------------------------------------------------------
1. เข้าไปในโฟลเดอร์โปรแกรม
2. ดับเบิลคลิกที่ไฟล์: "SETUP.bat"
3. ตัวติดตั้งจะทำงานให้อัตโนมัติทั้งหมด โดยที่คุณไม่ต้องไปหาโปรแกรมมาลงเอง:
   - ตรวจสอบ Python (หากยังไม่มีในเครื่อง ตัวติดตั้งจะดาวน์โหลดและลงให้เอง)
   - สร้างสภาพแวดล้อมเฉพาะ (Virtual Environment)
   - ติดตั้ง Library ที่จำเป็นทั้งหมด (Flask, Waitress, QRCode ฯลฯ)
   - เตรียมฐานข้อมูลและสร้างบัญชีผู้ใช้เริ่มต้น
   - สร้างปุ่มลัด (Shortcut) "PJ Copy Shop POS" บนหน้าจอ Desktop
   - เปิดสิทธิ์ Firewall ให้มือถือ/แท็บเล็ตในร้านเชื่อมต่อได้
4. เมื่อขึ้นข้อความ "ติดตั้งระบบ PJ Copy Shop POS เสร็จสมบูรณ์พร้อมใช้งาน!" ถือว่าเสร็จสิ้น!

------------------------------------------------------------------------
💻 ขั้นตอนที่ 2: การเปิดใช้งานระบบขายหน้าร้าน
------------------------------------------------------------------------
1. ดับเบิลคลิกที่ไอคอน "PJ Copy Shop POS" บนหน้าจอ Desktop
   (หรือดับเบิลคลิกไฟล์ "2_Start_POS.bat" ในโฟลเดอร์)
2. ระบบจะเปิดหน้าต่างเซิร์ฟเวอร์ และเปิดเว็บเบราว์เซอร์เข้าหน้า POS ให้อัตโนมัติ
   👉 http://localhost:5000 หรือ http://127.0.0.1:5000
3. ข้อมูลเข้าสู่ระบบเริ่มต้น:
   - ผู้ใช้งาน (User): Admin
   - รหัสผ่าน / PIN: 1234
4. 💡 คำแนะนำ: ให้ย่อหน้าต่างสีดำไว้ขณะขายของ ห้ามปิดหน้าต่างจนกว่าจะเลิกใช้งาน

------------------------------------------------------------------------
📱 ขั้นตอนที่ 3: การเชื่อมต่อจากมือถือหรือแท็บเล็ตในร้าน
------------------------------------------------------------------------
[วิธีที่ 1: เชื่อมต่อผ่าน Wi-Fi ในร้านเดียวกัน (ง่ายและเร็วที่สุด)]:
1. ให้มือถือหรือแท็บเล็ตเชื่อมต่อ Wi-Fi เดียวกันกับเครื่องคอมพิวเตอร์
2. ดูเลข IP ที่หน้าต่างสีดำของเครื่องคอมพิวเตอร์ (เช่น http://192.168.1.50:5000)
3. เปิดเบราว์เซอร์ (Chrome / Safari) บนมือถือ แล้วพิมพ์ที่อยู่ IP ดังกล่าวเพื่อใช้งานได้ทันที

[วิธีที่ 2: เชื่อมต่อผ่านอินเทอร์เน็ตภายนอกร้าน (Ngrok)]:
1. ดับเบิลคลิกที่ไฟล์ "Start_Mobile.bat"
2. ดูลิงก์ที่แสดงบนหน้าจอ แล้วนำไปเปิดบนมือถือ

------------------------------------------------------------------------
❓ การแก้ไขปัญหาเบื้องต้น (FAQ / Troubleshooting)
------------------------------------------------------------------------
Q: หากเปิดโปรแกรมแล้วขึ้นว่า "Port 5000 is already in use"?
A: แสดงว่ามีการเปิดโปรแกรมค้างไว้อยู่แล้ว ให้ดูที่แถบ Taskbar ด้านล่างหรือเปิดเว็บ http://localhost:5000 ใช้งานต่อได้เลย

Q: ต้องการสำรองข้อมูล (Backup Database)?
A: ไฟล์ฐานข้อมูลคือ "xerox.db" ในโฟลเดอร์โปรแกรม สามารถคัดลอกเก็บไว้ใน Flash Drive ได้ทุกวันหลังปิดร้าน
