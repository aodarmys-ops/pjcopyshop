# 🖨️ PJ Copy Shop — ระบบบริหารจัดการร้านถ่ายเอกสารและงานพิมพ์ครบวงจร
> **ระบบจัดการหน้าร้าน (POS), คลังสินค้า (Inventory), คิวงานพิมพ์ (Job Orders), ลูกค้าสัมพันธ์ (CRM) และบัญชีรายรับ-รายจ่าย (Accounting & Reports)**

---

## 📌 1. ขอบเขตของโปรแกรม (System Scope)

โปรแกรมนี้ได้รับการออกแบบและพัฒนาขึ้นโดยเฉพาะสำหรับ **ธุรกิจร้านถ่ายเอกสาร, งานพิมพ์ด่วน, รับเข้าเล่ม, ร้านจำหน่ายเครื่องเขียน และสินค้าของชำ/เครื่องดื่ม** เพื่อช่วยให้การดำเนินงานหน้าร้าน การควบคุมสต็อก และการตรวจสอบบัญชีเป็นไปอย่างรวดเร็ว ถูกต้อง และเป็นระบบ

### ขอบเขตการทำงานหลัก (Functional Scope):
- **ระบบทำงานแบบ Local In-House Server:** ทำงานได้ 100% ภายในเครื่องคอมพิวเตอร์ของร้าน ไม่จำเป็นต้องเชื่อมต่ออินเทอร์เน็ตในการขายหน้าร้าน (ยกเว้นฟังก์ชันการสำรองข้อมูลขึ้น Google Drive)
- **ระบบผู้ใช้งานแบบ PIN 6 หลัก:** เข้าถึงระบบด้วยรหัสผ่านความปลอดภัยสูง และป้องกันการเข้าถึงหน้าจัดการต่าง ๆ โดยไม่ได้รับอนุญาต (Route Protection)
- **การจัดการธุรกรรมแบบครบวงจร (End-to-End POS):** ตั้งแต่เปิดบิลขาย, จัดการสต็อกสินค้าปลีก, บริการถ่ายเอกสาร, งานสั่งทำ, ติดตามลูกหนี้, ตรวจนับสต็อก ไปจนถึงการปิดงบกำไรขาดทุน (P&L)

## 🚀 3. ความสามารถของโปรแกรม (Program Capabilities & Features)

### 3.1 ระบบความปลอดภัยและการยืนยันตัวตน (Authentication & Security)
- 🔐 **ระบบล็อกอินด้วย PIN 6 หลัก:** ปลอดภัย ใช้งานง่าย เหมาะกับการทำงานหน้าร้านที่ต้องกดรหัสอย่างรวดเร็ว
- 🛡️ **การป้องกันเส้นทางระบบ (Route Guards):** ทุกหน้าถูกป้องกันโดยสมบูรณ์ หากยังไม่ล็อกอิน ระบบจะส่งกลับไปหน้า `/login` ทันที
- 🔑 **การเปลี่ยนรหัสผ่าน (Change Password):** สามารถเปลี่ยนรหัส PIN ได้ด้วยตนเองที่หน้าล็อกอิน โดยระบบบังคับให้ยืนยันรหัส PIN เดิมก่อนเสมอ
- 🚪 **การออกจากระบบ (Logout):** มีปุ่มออกจากระบบที่ปลอดภัย และถอดปุ่ม "ปิดระบบ (Shutdown)" ออกจากหน้าแรก เพื่อป้องกันการสั่งปิดเซิร์ฟเวอร์โดยไม่ตั้งใจ

### 3.2 ระบบการขายหน้าร้าน (Point of Sale - POS)
- 🛒 **การขายสินค้าและบริการ:** ยิงบาร์โค้ด หรือค้นหาชื่อสินค้าเพื่อเพิ่มลงตะกร้าได้อย่างรวดเร็ว
- 💰 **การคำนวณเงินและปัดเศษ:** รองรับการคำนวณส่วนลด และปัดเศษขึ้นอัตโนมัติเพื่อง่ายต่อการทอนเงิน
- 💳 **ความหลากหลายของช่องทางการชำระเงิน:**
  - เงินสด (Cash) พร้อมคำนวณเงินทอน
  - โอนเงิน / พร้อมเพย์ (PromptPay) พร้อมแสดง QR Code
  - แบ่งชำระ (Split Payment: แบ่งจ่ายเงินสด + เงินโอน)
  - บิลค้างชำระ / บิลเชื่อ (Unpaid / Debt)
- 🚫 **ระบบป้องกันสินค้าขาดสต็อก (Out-of-Stock Guard):** ระบบตรวจสอบสต็อกแบบเรียลไทม์ และไม่อนุญาตให้ขายสินค้าเกินจำนวนที่มีในคลัง
- 🧾 **การออกใบแจ้งหนี้/ใบเสร็จ (Invoice Numbering):** ออกรหัสใบเสร็จเป็นลำดับต่อเนื่องอัตโนมัติในรูปแบบ `INVYYMM-XXXX` (เช่น `INV6909-0001`)

### 3.3 ระบบจัดการสินค้าและสต็อก (Inventory & Master Catalog)
- 🏷️ **แยกหมวดหมู่สินค้าและบริการ:**
  - สินค้าบริการ (Service): เช่น ถ่ายเอกสาร ขาวดำ/สี ไม่มีการตัดสต็อก
  - สินค้าปลีก (Retail/Stationery/Toys/Drinks): มีการนับและตัดสต็อกสินค้าอัตโนมัติเมื่อขาย
- ⚠️ **แจ้งเตือนจุดสั่งซื้อซ้ำ (Reorder Level):** ไฮไลต์เตือนสินค้าที่สต็อกต่ำกว่าเกณฑ์
- 🖨️ **การพิมพ์สติกเกอร์บาร์โค้ด (Barcode Printing):** ระบบสร้างและจัดพิมพ์บาร์โค้ดสำหรับติดบนตัวสินค้าที่ไม่มีบาร์โค้ดจากโรงงาน
- 🗑️ **การตัดของเสีย/สินค้าชำรุด (Stock Write-Off):** บันทึกการตัดสินค้าเสียหายออกจากคลัง พร้อมลงบัญชีค่าใช้จ่ายดำเนินงาน (OPEX) ตามมูลค่าต้นทุนให้อัตโนมัติ
- 📋 **ระบบตรวจนับสต็อกจริง (Physical Stock Count Audit):** บันทึกผลการตรวจนับเปรียบเทียบกับยอดในระบบ คำนวณผลต่าง (Variance) และปรับยอดสต็อกให้ตรงกับความเป็นจริง
- 📱 **รองรับการตรวจนับสต็อกด้วยมือถือ (Mobile Barcode Scanner):** 
  - รองรับการเปิดหน้าจอตรวจนับบนสมาร์ทโฟน/แท็บเล็ต พร้อมระบบเปิดกล้องสแกนบาร์โค้ดอัตโนมัติ
  - 🔄 **ระบบทำงานร่วมกัน (Auto-Join Session):** หากมีการตรวจนับในวันเดียวกัน ข้อมูลจากมือถือจะถูกรวมเข้ากับรอบการนับของ PC ให้อัตโนมัติ ทำให้สามารถช่วยกันนับหลายเครื่องได้
  - 🏷️ **การแยกแยะที่มาของการนับ:** ระบบแสดงรหัสแบบ **`MOB-XXXX`** สำหรับรายการที่มีการนับผ่านมือถือ และ **`CHK-XXXX`** สำหรับการนับผ่าน PC เพื่อให้ตรวจสอบง่าย
- 🌐 **รองรับเครื่องสแกนบาร์โค้ดในภาษาไทย (Global Barcode Fix):** หมดปัญหาลืมเปลี่ยนภาษาคีย์บอร์ด! ระบบสามารถแปลงตัวอักษรไทย (เช่น `ๅ/ภถุ`) กลับเป็นตัวเลขบาร์โค้ดภาษาอังกฤษให้อัตโนมัติในทุกหน้าจอที่มีการสแกน

### 3.4 ระบบสั่งซื้อสินค้าเข้าสต็อก (Purchasing & Inflow)
- 📥 **บันทึกการรับสินค้าเข้าสต็อก:** บันทึกชื่อคู่ค้า (Supplier), ราคาต้นทุน และจำนวนสินค้าที่รับเข้า
- 🧾 **รองรับภาษีมูลค่าเพิ่ม (VAT 7%):** เลือกคำนวณภาษีซื้อได้ตามความต้องการ
- ⚖️ **ระบบคำนวณต้นทุนถัวเฉลี่ย (Weighted Average Cost):** ปรับปรุงมูลค่าต้นทุนต่อหน่วยของสินค้าให้สะท้อนความเป็นจริงโดยอัตโนมัติ

### 3.5 ระบบคิวงานสั่งทำและงานพิมพ์ (Job Orders Workflow)
- 📝 **บันทึกคิวงาน:** บันทึกงานถ่ายเอกสารจำนวนมาก, งานเข้าเล่ม, พิมพ์งานพิเศษ พร้อมระบุเงินมัดจำ (Deposit)
- 🔄 **การติดตามสถานะงาน:** ติดตามสถานะงานตามขั้นตอน (รอดำเนินการ ➜ กำลังดำเนินการ ➜ ส่งมอบแล้ว ➜ ยกเลิก)
- 💵 **ส่งมอบและชำระเงิน:** บันทึกการส่งมอบงาน ระบบจะแปลงยอดเงินมัดจำและยอดคงเหลือเข้าสู่ระบบบัญชีการขายหน้าร้านทันที

### 3.6 ระบบลูกค้าสัมพันธ์และสะสมแต้ม (CRM & Loyalty Program)
- 👤 **ฐานข้อมูลสมาชิก:** บันทึกชื่อ, เบอร์โทรศัพท์ และประวัติการซื้อของลูกค้า
- ☕ **โปรแกรมสะสมแต้มเครื่องดื่มชง (Loyalty Points):**
  - ซื้อเครื่องดื่มชง (Brewed Drink) 1 แก้ว ได้รับ 1 แต้ม
  - สะสมครบ 10 แต้ม สามารถนำมาแลกรับส่วนลด 20 บาท
- 📒 **สมุดบัญชีลูกหนี้ (Customer Credit):** ติดตามยอดหนี้ค้างชำระของลูกค้าแต่ละราย และรองรับการนำบิลมาชำระย้อนหลังพร้อมออกใบเสร็จรับเงิน

### 3.7 ระบบบันทึกค่าใช้จ่าย (Expense Tracking)
- 💸 **บันทึกค่าใช้จ่ายรายวัน:** บันทึกค่าใช้จ่ายดำเนินงานร้าน (OPEX เช่น ค่าไฟ, ค่าน้ำมัน, ค่าของใช้) และรายจ่ายเพื่อการลงทุน (CAPEX)
- 🔍 **แยกช่องทางชำระเงิน:** ระบุวิธีจ่ายเงิน (เงินสด/เงินโอน) เพื่อให้ยอดกระทบยอดเงินสดในเกะได้อย่างแม่นยำ

### 3.8 ระบบรายงานและวิเคราะห์ผลประกอบการ (Financial Reports & P&L)
- 📊 **งบกำไรขาดทุนสุทธิ (P&L Report):** คำนวณรายได้สุทธิ, ต้นทุนขาย (COGS), กำไรขั้นต้น, ค่าใช้จ่ายรวม และกำไรสุทธิแบบเรียลไทม์
- 📅 **การกรองตามช่วงวันที่ (Date Range Filter):** เลือกดูรายงานเป็นรายวัน, รายเดือน หรือกำหนดช่วงวันที่ต้องการได้อย่างอิสระ
- 💵 **สรุปกระแสเงินสดหน้าร้าน (Cashflow Breakdown):** แสดงยอดแยกตามเงินสดในลิ้นชัก, เงินโอนเข้าบัญชี, และยอดค้างชำระ
- 🏆 **รายงานสินค้าขายดี:** แสดง 10 อันดับสินค้าที่ทำรายได้สูงสุด

### 3.9 ระบบดูแลรักษาและสำรองข้อมูล (Maintenance & Backup)
- ⚡ **ปุ่มจัดเรียงและกระชับฐานข้อมูล (VACUUM & Optimize):** กดเพียงคลิกเดียวจากหน้าแรกเพื่อจัดระเบียบและคืนพื้นที่ว่างในฐานข้อมูล ช่วยให้ระบบเร็วคงเส้นคงวาตลอดหลายปี
- 💾 **สำรองข้อมูลลงเครื่อง (Local Backup):** ดาวน์โหลดไฟล์สำรองข้อมูล (ZIP รวม CSV และฐานข้อมูล SQLite) เก็บไว้ในเครื่องคอมพิวเตอร์หรือแฟลชไดรฟ์
- ☁️ **สำรองข้อมูลขึ้น Google Drive:** ส่งออกและอัปโหลดไฟล์สำรองข้อมูลไปยัง Google Drive อัตโนมัติ
- 🔄 **การเรียกคืนข้อมูล (Restore Backup):** สามารถกู้คืนระบบจากไฟล์สำรองข้อมูลได้ทันทีเมื่อเกิดเหตุฉุกเฉิน

## 🛠️ 4. ขั้นตอนการติดตั้งและเริ่มต้นใช้งาน (Installation & Quick Start)

### 1. ติดตั้ง Python
ดาวน์โหลดและติดตั้ง **Python 3.10 ขึ้นไป** จาก [python.org](https://www.python.org/) (ต้องติ๊กเลือก `Add Python to PATH` ในระหว่างติดตั้ง)

### 2. ติดตั้งไลบรารีที่จำเป็น
เปิดโปรแกรม Terminal / PowerShell ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:
```bash
pip install -r requirements.txt
```

### 3. เริ่มต้นเปิดโปรแกรม
รันคำสั่งเปิดเซิร์ฟเวอร์:
```bash
python app.py
```

### 4. เข้าใช้งานระบบ
เปิดเว็บเบราว์เซอร์ (Chrome / Edge) แล้วไปที่:
```
http://127.0.0.1:5000
```
- **ผู้ใช้งานเริ่มต้น:** `Admin`
- **รหัส PIN เข้าใช้งาน:** `123456` (หรือรหัส PIN ที่คุณตั้งไว้)

### 5. การเปิดใช้งานกล้องสแกนบาร์โค้ดบนมือถือ (Ngrok)
เนื่องจากระบบความปลอดภัยของเบราว์เซอร์มือถือ (iOS/Android) บังคับให้การใช้งานกล้องต้องผ่าน `https://` เท่านั้น ระบบจึงมีไฟล์ `Start_Mobile.bat` เพื่อเชื่อมต่อผ่าน Ngrok ซึ่งจะสร้างลิงก์ปลอดภัยให้:
1. ติดตั้ง Ngrok ในเครื่องคอมพิวเตอร์หลัก (รัน `winget install ngrok.ngrok` ใน Terminal)
2. สมัครบัญชีที่เว็บ ngrok.com เพื่อขอรับ Authtoken และ Static Domain (ฟรี)
3. รันคำสั่ง `ngrok config add-authtoken [YOUR_TOKEN]` ในคอมพิวเตอร์
4. แก้ไขลิงก์ในไฟล์ `Start_Mobile.bat` ให้ตรงกับโดเมนของคุณ
5. ดับเบิลคลิก `Start_Mobile.bat` และนำลิงก์ไปเปิดบนเบราว์เซอร์มือถือ เพื่อใช้งานกล้องได้ทันที

## ☁️ 7. การตั้งค่าการสำรองข้อมูลขึ้น Google Drive

1. ไปที่ **[Google Cloud Console](https://console.cloud.google.com/)** สร้างโปรเจกต์ใหม่
2. เปิดใช้งาน **"Google Drive API"** ในเมนู *APIs & Services > Library*
3. ไปที่ *APIs & Services > OAuth consent screen* เลือก **External** และระบุอีเมลผู้ดูแล
4. ไปที่ *APIs & Services > Credentials* คลิก **Create Credentials > OAuth client ID** เลือกประเภท **Desktop app**
5. ดาวน์โหลดไฟล์ JSON เปลี่ยนชื่อเป็น **`credentials.json`** และนำมาวางไว้ที่โฟลเดอร์หลักของโปรแกรม
6. กดปุ่ม **"☁️ อัพโหลดขึ้น Google Drive"** ในหน้าแรกของระบบ จะมีหน้าต่างเด้งขึ้นมาให้ล็อกอินบัญชี Google เพียงครั้งแรกเท่านั้น
