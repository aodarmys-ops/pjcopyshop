# PJ Copy Shop - POS System

ระบบ POS สำหรับร้านถ่ายเอกสาร (Copy Shop) พร้อมด้วยระบบคลังสินค้า, บัญชีรายรับ-รายจ่าย, การจองคิวงาน, ระบบลูกค้าสมาชิก, โปรโมชั่น, จัดการสูตรการผลิต (BOM), และส่งรายงานขึ้น Google Sheets อัตโนมัติ

## ฟีเจอร์และสถาปัตยกรรมหลัก
- **ขายหน้าร้าน (POS)**: รองรับบาร์โค้ด, พิมพ์ใบเสร็จ, แยกชำระเงิน (Split)
- **คลังสินค้าและ BOM**: ตัดสต๊อกตามสูตรการผลิต, แจ้งเตือนของใกล้หมด พร้อมระบบคำนวณต้นทุน **WAC (Weighted Average Cost)** แบบอัตโนมัติ
- **คิวงานสั่งทำ (Job Orders)**: ติดตามสถานะงานพิมพ์ขนาดใหญ่
- **ลูกค้าและลูกหนี้**: สะสมแต้ม, ค้างชำระ (Unpaid/Credit)
- **บัญชี (P&L, Cashflow)**: บันทึกค่าใช้จ่าย, คำนวณกำไรขาดทุนตามหลักการบัญชี
- **Google Sheets Sync**: 
  - ระบบ **Incremental Sync (Sliding Window 90 วัน)** อัปเดตข้อมูลขึ้น Google Sheets เพื่อป้องกันปัญหาความจุเซลล์เต็ม 
  - ใช้งานร่วมกับ Dashboard สำเร็จรูป
- **ประสิทธิภาพสูง (Server-Side Pagination)**: ตารางแสดงผลทั้งหมด (การขาย, รายจ่าย, คิวงาน) ใช้เทคโนโลยี DataTables แบบ Server-Side Processing ทำให้รองรับปริมาณข้อมูล (Transaction) หลักแสนได้โดยไม่ทำให้เบราว์เซอร์ค้าง

## การติดตั้งและการรันระบบ
1. ติดตั้ง Library: รันสคริปต์ `1_Install.bat` หรือ `pip install -r requirements.txt`
2. รันระบบ: รันสคริปต์ `2_Start_POS.bat` หรือ `python run_server.py` (หรือ `python app.py`)
3. ใส่ไฟล์ `service_account.json` สำหรับ Google Sheets API (หากต้องการใช้งานระบบซิงค์)

## ระบบตั้งค่าสะสมแต้มและเครื่องดื่มชง (Loyalty Settings)
ระบบย้ายค่าคงที่ทางธุรกิจออกจากโค้ดทั้งหมด สามารถปรับแต่งได้ที่หน้า **ตั้งค่า (Settings)** แท็บ **🎁 สะสมแต้มและโปรโมชั่น**:
- **เปิด/ปิดระบบสะสมแต้ม**: เปิดหรือปิดการให้แต้มและการแลกแต้ม
- **หมวดหมู่สินค้าที่นับเป็นเครื่องดื่มชง**: เลือกได้หลายประเภทแบบไดนามิก (เช่น `Brewed Drink`, `Retail` ฯลฯ)
- **แต้มที่ได้รับต่อแก้ว**: กำหนดจำนวนแต้มที่จะได้รับต่อ 1 แก้วเครื่องดื่มชง (ค่าเริ่มต้น: 1 แต้ม)
- **อัตราการแลกแต้ม (หน่วยแลก)**: 
  - แต้มที่ใช้ต่อ 1 หน่วยแลก (ค่าเริ่มต้น: 10 แต้ม)
  - ส่วนลดบาทต่อ 1 หน่วยแลก (ค่าเริ่มต้น: 20 บาท)
  - *สูตรคำนวณส่วนลด*: `loyalty_discount = (redeemed_points // points_per_unit) * discount_per_unit`
  - ตรวจสอบความถูกต้องที่ Server ทุกครั้ง และเก็บบันทึก `loyalty_discount` และ `redeemed_points` จริงลงบิลขาย ไม่คำนวณย้อนหลังจากค่าปัจจุบัน

## ระบบโปรโมชั่น (Promotions Engine)
ระบบโปรโมชั่นทำงานจริงทั้งหน้าร้าน (POS) และหลังบ้าน (Server Evaluation & Validation):
### ชนิดโปรโมชั่นที่รองรับ (Promotion Types):
1. **ลดเป็นเปอร์เซ็นต์ (Percentage Discount)**: เช่น ลด 10% ทั้งบิล หรือเฉพาะหมวด
2. **ลดเป็นจำนวนเงินบาท (Fixed Amount Discount)**: เช่น ลดทันที 20 บาท
3. **ซื้อครบยอดเงิน ลดบาท (Spend X Discount Y)**: เช่น ซื้อครบ 100 บาท ลด 10 บาท
4. **ซื้อครบจำนวนชิ้น ลดบาท (Quantity Tier Discount)**: เช่น ซื้อครบ 3 ชิ้น ลด 15 บาท
5. **ซื้อครบจำนวนชิ้น แถมฟรี (Buy X Get Y Free)**: เช่น ซื้อครบ 2 ชิ้น แถม 1 ชิ้น (ลดตามราคาสินค้าชิ้นที่แถม)

### เงื่อนไขและขอบเขต (Scope & Conditions):
- **ขอบเขตสินค้า (Target Scope)**:
  - `ทุกสินค้า (All Products)`: คำนวณยอดรวมทั้งบิล
  - `เฉพาะหมวดหมู่ (Category)`: คำนวณเฉพาะสินค้าในหมวดที่เลือก (เช่น `Brewed Drink`)
  - `เฉพาะสินค้าที่ระบุ (Specific Product)`: คำนวณเฉพาะรายการสินค้านั้นๆ
- **เงื่อนไขขั้นต่ำ (Condition Type & Value)**:
  - `ไม่มีเงื่อนไข (None)`: ใช้ได้ทันที
  - `ยอดซื้อขั้นต่ำ (บาท) (Min Spend)`: ต้องมียอดสินค้าที่ร่วมรายการถึงจำนวนที่กำหนด
  - `จำนวนชิ้นขั้นต่ำ (ชิ้น) (Min Quantity)`: ต้องมีจำนวนชิ้นถึงเกณฑ์
- **การใช้ร่วมกันและลำดับความสำคัญ (Priority & Stacking)**:
  - **ลำดับความสำคัญ (Priority)**: โปรที่มี Priority สูงกว่าจะได้รับการคำนวณก่อน
  - **ใช้ร่วมกับโปรอื่นได้ (Stackable)**: หากไม่ติ๊ก จะเลือกโปรเดี่ยวที่ให้ส่วนลดสูงสุดแก่ลูกค้า
  - **ใช้ร่วมกับแต้มสะสมได้ (Allow with Loyalty)**: ควบคุมการใช้ร่วมกับแต้มแลกเครื่องดื่ม
  - **ส่วนลดสูงสุด (Max Discount Cap)**: กำหนดยอดลดสูงสุดเป็นบาทต่อบิล
  - **วันเริ่มและสิ้นสุด**: โปรโมชั่นจะทำงานเฉพาะในช่วงวันที่ที่กำหนดและมีสถานะเปิดใช้งาน

### การคำนวณที่ฝั่งเซิร์ฟเวอร์ (Server-Side Recalculation):
- ทุกคำขอชำระเงินที่ `POST /api/sales` จะคำนวณส่วนลดโปรโมชั่นใหม่จากฐานข้อมูลเสมอ ป้องกันการส่งยอดปลอมจาก Client
- รวมส่วนลดตามสูตร: `discount = manual_discount + loyalty_discount + promo_discount`
- ยอดสุทธิปัดเศษขึ้น: `total_amount = math.ceil(max(0, subtotal - discount))`
- บันทึกรายละเอียดโปรโมชั่นที่ใช้จริงลงตาราง `Sale_Promotions` (sale_id, promo_id, promo_name, discount_amount)
- สต๊อกและรายงานยอดขายแสดงยอดส่วนลดโปรโมชั่นแยกต่างหาก รองรับการยกเลิกบิล (Void) อย่างถูกต้อง

## โค้ดสำหรับ Google Apps Script (Dashboard)
โค้ดสำหรับนำไปวางใน Google Apps Script (เพื่อให้แสดง Dashboard วิเคราะห์ยอดขายและวางแผนสั่งของ) อยู่ในโฟลเดอร์ `gas_dashboard`:
1. `gas_dashboard/Code.gs` -> วางใน `Code.gs` ของ Apps Script
2. `gas_dashboard/Index.html` -> สร้างไฟล์ `Index.html` และวางโค้ดใน Apps Script
*(อย่าลืมตั้งค่า `XFrameOptionsMode.ALLOWALL` เพื่อให้ฝังใน Google Site ได้)*
