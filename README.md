# ระบบจัดการร้านถ่ายเอกสาร (Xerox Management System)

## การสำรองข้อมูลขึ้น Google Drive (Google Drive Backup)

ระบบมีฟังก์ชันสำหรับสำรองข้อมูลทั้งหมดในฐานข้อมูล (ไฟล์ CSV ของทุกตาราง + ไฟล์ `xerox.db`) และอัพโหลดขึ้นไปเก็บบน Google Drive ได้โดยตรง เพื่อความปลอดภัยของข้อมูล

### ข้อกำหนดก่อนการใช้งาน (Prerequisites)

เนื่องจากระบบทำงานบนเครื่องส่วนตัว (Local) และต้องการอัพโหลดไฟล์ไปยังบัญชี Google Drive ของคุณโดยตรง จึงจำเป็นต้องตั้งค่าสิทธิ์ให้โปรแกรม (Google Cloud) และต้องมีไฟล์ `credentials.json` อยู่ในโฟลเดอร์โปรเจกต์ `d:\xerox`

### ขั้นตอนการตั้งค่า Google API (สร้าง credentials.json)

1. เข้าไปที่เว็บไซต์ **[Google Cloud Console](https://console.cloud.google.com/)**
2. สร้างโปรเจกต์ใหม่ (Create Project)
3. ไปที่เมนู **"APIs & Services" > "Library"** ค้นหา **"Google Drive API"** แล้วกด **"Enable"**
4. ไปที่เมนู **"APIs & Services" > "OAuth consent screen"**
   - เลือก **External** และกรอกข้อมูลบังคับให้ครบถ้วน (ชื่อแอป, อีเมลติดต่อ)
   - ในส่วนของ **Test users** ให้เพิ่มอีเมล Gmail ของคุณเองลงไป (เพื่อให้อนุญาตตัวเองทดสอบระบบได้)
5. ไปที่เมนู **"APIs & Services" > "Credentials"**
6. คลิก **"+ CREATE CREDENTIALS"** เลือก **"OAuth client ID"**
7. ช่อง **Application type** ให้เลือก **"Desktop app"** แล้วตั้งชื่อตามต้องการ จากนั้นกด Create
8. จะมีหน้าต่างขึ้นมา ให้คลิกปุ่ม **"DOWNLOAD JSON"**
9. นำไฟล์ที่ดาวน์โหลดมา เปลี่ยนชื่อให้เป็น **`credentials.json`** และนำไปวางไว้ในโฟลเดอร์หลักของโปรแกรม (โฟลเดอร์ที่มีไฟล์ `app.py`)

### ขั้นตอนการใช้งานการสำรองข้อมูล (การอัพโหลดครั้งแรก)

1. เข้าใช้งานระบบ เลือกเมนู **"หน้าแรก (แดชบอร์ด)"**
2. ในส่วนของ **สำรองข้อมูล** คลิกปุ่ม **"☁️ อัพโหลดขึ้น Google Drive"**
3. **เฉพาะการอัพโหลดครั้งแรกสุด:** หน้าต่างเบราว์เซอร์จะเด้งขึ้นมา เพื่อให้คุณล็อกอินเข้าสู่ระบบบัญชี Google ของคุณ
4. กดอนุญาตให้แอปพลิเคชันเข้าถึง Google Drive 
   *(หมายเหตุ: หากขึ้นหน้าจอเตือนว่าแอปยังไม่ได้รับการยืนยัน "Google hasn't verified this app" ให้คลิกที่ **"Advanced" (ขั้นสูง)** แล้วคลิก **"Go to [ชื่อแอป] (unsafe)"**)*
5. เมื่อกดยอมรับสำเร็จ กลับมาที่หน้าเว็บ ระบบจะแจ้งว่าสำรองข้อมูลสำเร็จ และเปิดหน้า Google Drive ที่มีไฟล์สำรองให้ดูทันที
6. ในการอัพโหลดครั้งต่อๆ ไป คุณไม่จำเป็นต้องล็อกอินอีก ระบบจะอัพโหลดขึ้นไปให้ทันที!

> *หมายเหตุ: โปรแกรมจะบันทึกสิทธิ์การเข้าสู่ระบบของคุณไว้ในไฟล์ `token.json` เก็บไว้อย่างปลอดภัยในเครื่องของคุณ*
